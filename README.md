## Zennの本『Nature Knows Only Addition ― 整数値で読み解く数学の諸問題 ―』の連動リポジトリです。

この本は、前の本で示した足し算から三角関数までの道具を使って、フィボナッチ数列から始まり、素数・幸運数・円周率公式へと進んでいきます。更に、数学上の諸問題を整数値だけで読み解きます。

表紙の盤を見ると、フィボナッチ数も素数も幸運数も、足し算の動きのどこを数えるかの違いで分かれて出て来るかわかります。第1章では、その出発点である二つの 1 から始めます。
