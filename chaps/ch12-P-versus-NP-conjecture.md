第12章　P≠NP予想
---

## 12.1 P≠NP予想とは何か？

ジグソーパズルを思い浮かべてください。完成した絵を見せられて「これで合っているか」と聞かれたら、一目で答えられます。けれども、ばらばらのピースから絵を完成させるのは、ずっと時間がかかります。

もう一つ。何枚かの数の札から、何枚かを選んで足し、ちょうど 150 にしてください。

> 4, 9, 13, 22, 30, 47, 61, 85

答えの組 4 ＋ 9 ＋ 22 ＋ 30 ＋ 85 を渡されたら、足して 150 になるかは一度で確かめられます。けれども、自分で組を探すとなると、どの札を使うかの組み合わせは 2⁸ ＝ 256 通りあります。札が 20 枚なら百万通り、40 枚なら一兆通りです。

確かめるのは易しい。探すのは難しい。この二つの間に、本当に越えられない差があるのか。これが **P≠NP 予想** です（P は「速く解ける問題」、NP は「答えを速く確かめられる問題」）。1971 年にクックが問いの形に整え、ミレニアム懸賞問題の一つになっています。

この本では、ここまでに二つのことを見てきました。第3章では、フィボナッチの札なら、大きい札から引けるだけ引くだけで、迷わずにどの番地にも届きました。第8章では、札の和で届く数を、一本のビット列に「ずらして重ねる」ことで塗っていきました。この章では、この二つをつなぎ、別々に書いてきたアメーバの記事を一つの流れにして、P≠NP を見ていきます。

## 12.2 B13 の言葉で見ると

### 探す道と、確かめる一歩

札を一枚ずつ見ていき、各札で「足す」か「足さない」かを決めます。番地を

> （何枚目の札まで見たか, ここまでの和）

と取ると、各番地から出る道は「足す」と「足さない」の二本だけです。スタート（0 枚目, 和 0）から出て、最後の段で目標の和に着地すれば、答えが見つかったことになります。

この番地の集まりを、**部分和の地図**と呼びます。札を一枚見るたびに、届く和の集まりを「ずらして重ねる」と、地図の次の段ができます。第8章で、グレアムの札の穴を探したのと同じ操作です（既存の言葉では：部分和問題の動的計画法）。

確かめるのは、組を足して目標と比べる、足し算一回と比べ合い一回です。探すのは、この地図の上を歩くことです。

### アメーバは、匂いの濃い方へ寄る

別の記事「アメーバは地図を検索できるか ― 全部の道を足して、濃い方へ寄る ―」では、ペンローズの床の上で、餌の匂いを地図のすべての道に均等に広げ、アメーバがその濃い方へ寄るだけで、最短の道が現れることを見ました。各番地は、隣の値を足すだけです。

同じことを、部分和の地図でやります。

- 餌を、最後の段の目標の和に置く。
- 匂いを、道に沿って逆向きに広げる。各番地の濃さは、「足さない道の先の濃さ」と「足す道の先の濃さ」の和。足し算だけ。
- 番地の濃さは、そこから目標へ届く道の本数になる（既存の言葉では：全経路の和、経路積分の離散版）。
- スタートに匂いが届いていれば、答えがある。濃さはそのまま、答えの組の数。
- アメーバは、匂いのある方へ一段ずつ寄るだけで、答えの組を一つ取り出せる。途中で迷わない。

匂いを広げることが「探す」ことで、取り出した組を足すことが「確かめる」ことです。

### フィボナッチの札には、近道がある

第3章の「忘れても届く」では、フィボナッチの札 1, 2, 3, 5, 8, 13, 21 の組み合わせで、番地 33 まで欠けずに届きました。届き方は一つだけで、大きい札から引ける札を引いていくだけでした（既存の言葉では：ツェッケンドルフの表現、貪欲法）。

フィボナッチの札なら、匂いを地図全体に広げる必要がありません。大きい札から引くだけの一本道で、札の枚数だけの歩数で答えに着きます。構造がある札では、探すことが消えます。

ばらばらな札には、この近道がありません。大きい札から引くだけでは届かない目標が出てきます。そのときは、匂いを地図全体に広げるしかありません。

### 地図は、札が一枚増えるごとに倍に広がる

部分和の地図の広さは、二つのものに縛られています。

- 和の大きさ（札の桁）：和は 0 から札の合計までしか取れない。
- 札の枚数：n 枚の札の選び方は 2ⁿ 通り。

札の桁が小さいうちは、違う選び方が同じ和に重なるので、地図は和の大きさで頭打ちになります。札の桁が大きくなると、和はほとんど重ならなくなり、地図は選び方の数、つまり札が一枚増えるごとに倍に広がります［計算］。

```
札 14 枚の地図の点の数（各桁 20 組の平均）
桁 1      472
桁 2     3171
桁 3    13878
桁 4    28510
桁 5    32231
桁 7    32767   ＝ 選び方の数を段ごとに足した上限
```

一方、ペンローズの床の最短路では、多くの道が同じ交差点を通ります。点が重なるので、地図は床の広さのままで、爆発しません。匂いは床の端まで追いつき、アメーバは最短の道を見つけます（既存の言葉では：最短路問題は P に属する）。

### 宇宙は無限でも、匂いは一歩ずつしか広がらない

［監督の発話］ペンローズの担体は宇宙と同じで、限界がない。しかし匂いはオートマトンで進んでも、担体の広がりに追いつけない。それが NP の答え。

ふつうの計算機では、足りなくなるのは場所（記憶）です。ペンローズの担体は限りなく広く、どの五芒星も違う景色を持つので、地図を置く場所はいくらでもあります。

足りなくなるのは、匂いが広がる速さ、つまり時間です。匂いは一歩に一段しか進みません。札が一枚増えるごとに倍に広がる地図に、一歩ずつ広がる匂いは追いつけません。

［監督の発話］「証明はできないが自明」というリーマン予想と同じ位置の答えで十分。数学者ではないので。

第7章で、リーマン予想を「素数の残渣は √x の放物線の中を歩く」として、証明はできないが、そうなっているほうが自然だと見ました。P≠NP も、同じ位置に置きます。

> 宇宙は無限でも、匂いは一歩ずつしか広がらない。札ごとに倍に広がる地図に、匂いは追いつけない。

ただし、ここで言えるのは「このやり方（全部の道に匂いを広げる）では、時間で負ける」までです。「どんなやり方でも負ける」ことは言えません。フィボナッチの札のように、近道を持つ札があります。どんな札にも近道がないことを示せれば、それが P≠NP の証明になります。そこは、アメーバには決められません。

## 12.4 走らせた検定

**事前に決めたこと**

- 地図の点は、届く和を一本のビット列に「ずらして重ねる」ことで数える。匂いの濃さは、道の先の濃さを足すだけで求める。判定は整数の比べ合いだけで行う。
- 検定1：札 14 枚で、札の桁を 1 から 7 まで増やしたとき、地図の点の数がどう広がるかを数える。
  - 対照：フィボナッチの札 14 枚では、1 から札の合計までのどの目標にも、大きい札から引くだけの一本道（14 歩）で届くこと。ばらばらに近い札では、一本道では届かない目標が出ること。
- 検定2：札 4〜12 枚の 300 組で、「スタートに匂いが届くか」が総当たりの答えと一致すること。スタートの濃さが答えの組の数と一致すること。取り出した組が必ず目標に着地すること。届かない目標では NG を返すこと。
  - 対照：餌を目標から一つずらした番地に置くと、答えが総当たりと食い違うこと。
- 検定3：最短路の地図（L × L の格子）では、点の数が L × L のまま増え、匂いが端まで届く歩数が L に比例すること。部分和の地図（各札 7 桁）では、点の数が札の枚数ごとに倍に増えること。

**スクリプト（要所）**

```python
def layers(cards):
    R = 1; out = [R]
    for c in cards:
        R = R | (R << c); out.append(R)      # ずらして重ねる（第8章）
    return out

def smell_back(cards, target):
    D = [dict() for _ in range(n + 1)]; D[n][target] = 1   # 餌
    for i in range(n - 1, -1, -1):
        for s, v in D[i + 1].items():
            D[i][s] = D[i].get(s, 0) + v                      # 足さない道
            if s - cards[i] >= 0:
                D[i][s - cards[i]] = D[i].get(s - cards[i], 0) + v   # 足す道
    return D
```

**読み**

- ［計算］部分和の地図は、札の桁が小さいうちは和の重なりで頭打ちになり、桁が大きくなると選び方の数（札 n 枚で 2ⁿ⁺¹ − 1）まで広がりました。
- ［計算］匂いの答えは、300 組すべてで総当たりと一致し、匂いの濃さは答えの組の数そのものでした。濃い方へ寄って取り出した組は、すべて足し算一回で目標に着地しました。
- ［計算］フィボナッチの札では、匂いを広げずに一本道で届きました。ばらばらに近い札では、一本道では届かない目標が 556 個ありました。
- ［計算］最短路の地図は、床の広さのまま増え、匂いは床の辺の長さに比例する歩数で端まで届きました。部分和の地図は、札が一枚増えるごとに倍に広がりました。

## 12.5 どこまで来ているか

［知識］P≠NP 予想は未解決です。

- **問いの形**：クック（1971）とレヴィン（1973）が独立に、「NP 完全」という問題の族を定めました。部分和問題もその一つです（カープ 1972）。NP 完全な問題のどれか一つでも速く解ければ、NP のすべての問題が速く解けます。
- **多くの研究者の見立て**：P≠NP だと考える研究者が大多数ですが、証明はありません。証明の道を塞ぐ壁もいくつか知られています（相対化、自然な証明、代数化）。
- **擬多項式**：部分和問題は、和の大きさに比例する手間で解けます（この章の地図）。札の桁が増えると、その手間が指数的に増えます。NP 完全の難しさは、この「桁」の側に現れます。

この章では、別々に書いてきた三つのもの、すなわちフィボナッチの札（第3章）、ずらして重ねる地図（第8章）、アメーバの匂い（記事「アメーバは地図を検索できるか」）を、一つの地図の上に並べました。そこで言えたのは、「全部の道に匂いを広げるやり方は、札が増えると時間で負ける」ことと、「構造のある札には、匂いを広げなくてよい近道がある」ことです。どんなやり方でも負けるかどうかは、B13 の言葉で見ても、証明できるところまでは届いていません。

## 12.6 まとめ

答えを確かめるのは、組を足して目標と比べる一歩です。答えを探すのは、部分和の地図の上を歩くことです。

アメーバは、目標から匂いを地図の道に沿って広げ、濃い方へ寄るだけで答えの組を取り出します。匂いの濃さは、答えの組の数そのものです。フィボナッチの札なら、匂いを広げずに一本道で着きます。ばらばらな札では、札が一枚増えるごとに地図が倍に広がり、匂いはその全体に広がらなければなりません。

ペンローズの床は宇宙のように限りなく広く、場所は足ります。足りないのは、一歩ずつしか広がらない匂いの速さです。だから P≠NP は、第7章のリーマン予想と同じく、証明はできないが、そうなっているほうが自然に見えます。
