## 4.1 はじめに

太鼓を叩く人が、何人も一列に並んでいるところを思い浮かべてください。拍は 1, 2, 3, 4, … と、一つずつ進んでいきます。

最初の人は、2 拍目から始めて 2 拍ごとに太鼓を叩きます。2, 4, 6, 8, … です。

拍を進めていくと、3 拍目には誰も叩いていません。そこで、2 人目が加わります。この人は 3 拍目から 3 拍ごとに叩きます。3, 6, 9, … です。

4 拍目には 1 人目が叩きます。5 拍目には誰も叩いていないので、3 人目が加わって 5 拍ごとに叩き始めます。6 拍目は 1 人目と 2 人目が同時に叩くので、音が重なります。

こうして、「誰も叩いていない拍が来たら、そこから新しい人が加わる」という決まりだけで拍を進めていくと、新しい人が加わる拍は 2, 3, 5, 7, 11, 13, … になります。これは素数です。

この章では、素数を「篩から落ちずに残った数」としてではなく、「篩を作っていく波そのもの」として見ます。一人ひとりの太鼓が、それぞれ周期の決まった波です。素数は、その波を重ねていくなかで、新しい波が生まれる場所です。

## 4.2 B13 の言葉で見ると

### 篩は波の重ね合わせ

周期 p の波は、p, p + p, p + p + p, … に山が来ます。数を 2 から順に見ていき、次のことだけをくり返します。

1. 今見ている数に、これまでに立てたどの波の山も来ていなければ、その数を周期とする新しい波を立てる。
2. 次の数へ進む。

立てる波の周期は、前もって決めていません。数を順に見ていくなかで、篩そのものが決めます。そして、立った波の周期が素数です。

第2章では、素数を「値で印をつけて外していった残り」として見ました。ここでは同じことを、印をつける側、つまり波の側から見ています。外していくのは波の山で、残るのは、山が一度も来なかった拍です。素数は篩から落ちる数ではなく、篩そのものを作っていく数です。

### 合成波の谷に素数が落ちる

周期 p の波を、なめらかな cos 波 cos(2πx/p) で描きます。p の倍数のところで山（高さ 1）になり、そのあいだで谷になる波です。数を順に見ていきながら立てた cos 波を、すべてそのまま足し合わせたものを**合成波**と呼びます。どこも切ったり継いだりしていない、なめらかな波です。

60 までに立つ波は、2 から 59 までの 17 本です。この 17 本を足した合成波で、整数の位置の谷（両隣より低い所）を見ると、次のようになります。

- 5 から 59 までの素数は、すべて谷に落ちます。
- 谷に落ちないのは、最初に立った 2 と 3 だけです。
- 谷には、9, 25, 27, 35, 49, 55 のような素数でない数も落ちます。

なめらかな cos 波を足した合成波の谷は、素数をほとんどすべて含みますが、素数だけにはなりません。

### 倍音を重ねると、谷が素数に揃う

（ここは動く図には入れていません。）周期 p の波を、周期 p, p/2, p/3, …, p/(p − 1) の cos 波と高さ 1 の平らな波、あわせて p 本の重ね合わせにします（p で割る）。これも cos 波だけでできた、なめらかな波です。

> 周期 p の波 ＝（cos 波 p 本の和）÷ p

整数の位置では、この波は p の倍数でちょうど 1、それ以外でちょうど 0 になります。p の倍数のところでは p 本の cos 波の山がそろい、それ以外では山と谷が打ち消し合うからです。60 までの篩に要る 2, 3, 5, 7 の四本（8 × 8 が 60 を越えるので 7 までで足りる）をこの形にして足すと、合成波は 8 から先では素数のところでちょうど 0 まで沈み、それ以外では持ち上がります。山を細くする倍音を足すと、谷が素数にぴったり揃います。

［知識］ある周期の山の並びを、いろいろな周期の cos 波の重ね合わせで書くことは、フーリエ変換（計算機では FFT）として知られています。なめらかな cos 波一本は、そのいちばん低い音（基音）だけを取ったもので、倍音を足すほど山が細くなります。

### 材料は 2 と 3

2 以上のどの数も、2 と 3 を足して作れます（2a + 3b）。偶数は 2 を並べるだけで、奇数は 3 を一つと残りの 2 を並べます。立った波の周期も同じです。

> 5 = 2 + 3、7 = 2 + 2 + 3、11 = 2 + 2 + 2 + 2 + 3、13 = 2 + 2 + 2 + 2 + 2 + 3

どの波も、2 と 3 の足し算でできた歩幅で進みます。篩をいくら細かくしても、材料は 2 と 3 だけです。

### 波が打ち消し合う骨組み

波を正弦波として描くと、周期 p の波は p の倍数のところで山になります。p の倍数でないところでは、ずらした波をいくつも重ねると、山と谷が打ち消し合います。

この打ち消し合いには、整数の骨組みがあります。p 番地の輪の上を、n ずつ p 回進んでみます。

- n が p の倍数なら、何度進んでも番地 0 に留まり、番地 0 に p 回止まる。
- n が p の倍数でなければ、輪の全番地にちょうど 1 回ずつ止まって、出発点に戻る。

全番地に 1 回ずつ均等に止まるのが「打ち消し合う」こと、番地 0 に p 回重なるのが「山が立つ」ことです。正弦波の重ね合わせは、輪の上を足し算で進む歩き方として、そのまま書けます。

### ペンローズの鎖も二本の波

第2章 2.5 で、ペンローズタイリングの円環をつないだ鎖で数を表しました。この鎖も、波として読めます。

- 奇数の鎖の一歩は、二つの向きを交互にくり返します。山と谷を交互にたどる波です。
- 二つの向きは、鎖の軸に対して鏡に映した関係にあります。どちらの向きから始めるかで、位相が半周期ずれた二本の波になります。これが 2 種類の奇数です。
- 二歩ぶんの和は、奇数の鎖でも偶数の鎖でも、まったく同じ格子の一歩になります。偶数の鎖は、二本の波が交わる中心線の上を進む、と読めます。
- V 字（3 環）の端から端は、ちょうど二歩ぶん、つまり波の 1 周期です。

2 の打ちは「中心線を進むか、波をたどるか」として、3 の打ちは「波の 1 周期」として、ペンローズの鎖の形に出ています。

これを、半周期ずれた二本のなめらかな cos 波の上に、鎖の円環を乗せて描いたのが次の図です。半周期は円環の間隔から決まる 4.028740、振幅は 1.463525 で、どちらもペンローズの格子から出る値です。

### フィボナッチの点も二本の双曲線を跳ぶ

第1章で、フィボナッチ数列を (直前の数, 今の数) の組の歩みとして書きました。この組を平面の点 (x, y) = (今の数, 直前の数) として置きます。

> (1, 0), (1, 1), (2, 1), (3, 2), (5, 3), (8, 5), …

どの点でも、Q = x·x − x·y − y·y を計算すると、+1 と −1 が交互に出ます。

> (2, 1)：4 − 2 − 1 = +1、(3, 2)：9 − 6 − 4 = −1、(5, 3)：25 − 15 − 9 = +1

Q = +1 の点と Q = −1 の点は、それぞれ一本の双曲線の上にあります。フィボナッチの点は、この二本の双曲線のあいだを一歩ごとに跳び移りながら登っていきます。二本のあいだには Q = 0 の線 x = φy が通っていて、点はこの線にどこまでも近づきますが、整数の点がこの線に乗ることはありません。

跳び先の Q を一歩ずつ並べると、+1, −1, +1, −1 と、cos 波の山と谷に交互に乗ります。一歩が半周期、二歩で 1 周期です。ペンローズの奇数の鎖が cos 波の山と谷を交互にたどり、二歩で 1 周期になったのと、同じ刻みです。二本の双曲線が、中心線をはさんだ二本の波の位置にあたります。

```python
def wave_sieve(N):
    hits = [0] * (N + 1)
    waves = []
    n = 2
    while n <= N:
        if hits[n] == 0:                 # どの波も鳴らない ⇒ 新しい波を立てる
            waves.append(n)
            v = n
            while v <= N:
                hits[v] += 1; v += n
        n += 1
    return waves, hits

def composite_wave(N):
    """波の山を p+p, p+p+p, … に置いて足し合わせた合成波。値は来ている山の数"""
    C = [0] * (N + 1)
    waves = []
    n = 2
    while n <= N:
        if C[n] == 0:                    # 合成波の谷の底 ⇒ 新しい波を立てる
            waves.append(n)
            v = n + n
            while v <= N:
                C[v] += 1; v += n
        n += 1
    return waves, C

def ring_walk(p, n):
    """p 番地の輪を n ずつ p 回進む。止まった番地を数える。"""
    cnt = [0] * p; a = 0
    step = n
    while step >= p: step -= p
    for _ in range(p):
        cnt[a] += 1
        a += step
        if a >= p: a -= p
    return cnt
```

- ［計算］山が一つだけ来る数は、素数のほかに 4, 8, 9, 16, 25 … のような素数のべきも含みます。素数を決めるのは「山が一つ」ではなく、「それより前のどの波の山も来なかった」ことです。
- ［計算］波の山を p + p から置いた合成波では、10000 までで値 0 の谷の底が 1229 個あり、立った波の周期と一致しました（1000 までは別の方法で確かめた素数とも一致）。自分の位置にも山を置くと、谷の底は 1 だけになりました。素数は、合成波の谷の底に並んでいます。
- ［計算］p 番地の輪を n ずつ p 回進むと、p の倍数のときだけ番地 0 に重なり、それ以外は全番地に均等に止まりました。正弦波の山と打ち消し合いが、輪の上の足し算として成り立っています。
- ［計算］cos 波だけで書いた合成波は、整数の位置で、来ている山の数と 10⁻¹³ の桁まで一致しました。整数の合成波と、cos 波の合成波は同じものです。
- ［計算］立った cos 波 17 本をすべて足した合成波では、5〜59 の素数がすべて谷に落ち、落ちないのは最初の 2 と 3 だけでした。素数でない谷は 9, 25, 27, 35, 49, 55 でした。
- ［計算］√N までの波 2, 3, 5, 7 だけを足しても、11〜59 の素数はすべて谷に落ちました。素数でない谷は 9, 25, 27, 35, 49, 55 の 6 個でした。200 まで広げて 13 までの波を使うと、89 だけが谷に落ちず、素数でない谷も増えました。なめらかな cos 波一本ずつの谷は、素数のおおまかな居場所を示します。
- ［計算］倍音まで重ねると、8〜60 で合成波が 0 になる数は 11〜59 の素数とちょうど一致しました。
- ［計算］記録の cos 波 2 本に、奇数の鎖（n = 1〜29）の円環は 10⁻¹⁴ の桁まで乗り、偶数の鎖の偶数番の円環はすべて二本の波の交点に乗りました。
- ［計算］ペンローズの鎖は、奇数では鏡に映した二つの向きを交互にたどり、二歩ぶんの和は偶数の鎖と同じ格子の一歩でした。V 字はちょうど波の 1 周期です。
- ［計算］2〜1000 のどの数も 2 と 3 の足し算で書けました。立った波の周期も、すべて 2 と 3 でできています。

## 4.4 どこまで来ているか

［知識］素数を波の重ね合わせで見る考え方は、数学の中心にあります。

- 周期 q の波を、q と互いに素なずらし方だけで重ねたものは「ラマヌジャン和」と呼ばれます。ラマヌジャンは、このような波の重ね合わせで数の性質を書く方法を残しました。第6章では、ラマヌジャンの円周率の公式（1103 と 26390、第二の公式の 1123 と 21460）を、足し算の列の重ね合わせとして見直します。
- 素数がどう並ぶかは、ある関数（ゼータ関数）の零点から作られる無数の波を重ね合わせた式で書けることが知られています。その波のもとになる零点が、すべて一本の縦の線（実部が 1/2 の線）の上に並ぶかどうか、というのがリーマン予想です。第7章で扱います。

ペンローズの鎖の形に直接出るのは、2 の打ちと 3 の打ちまででした（第2章 2.5）。5 から先の打ちは、2 と 3 を足して組んだ歩幅の波として、この章の重ね合わせが引き継ぎます。

## 4.6 まとめ

数を 2 から順に見ていき、どの波の山にも当たらない数で新しい波を立てる。この決まりだけで、立つ波の周期は素数になりました。なめらかな cos 波を足した合成波を描くと、5 から 59 までの素数はすべてその谷に落ちました。倍音まで重ねると、谷はちょうど素数に揃いました。素数は、篩から落ちずに残る数というより、篩を作っていく波の周期そのものです。

どの波の歩幅も 2 と 3 の足し算でできていて、波の山と打ち消し合いは、輪の上を足し算で進む歩き方として書けました。ペンローズタイリングの鎖も、鏡に映した二本の波として、2 の打ちと 3 の打ちをそのまま形に持っていました。

波を重ねて素数を見るこのやり方は、第6章のラマヌジャン、第7章のリーマン予想へと続いていきます。
