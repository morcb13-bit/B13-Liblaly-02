## 8.1 エルデシュ問題 #346 とは？

第3章の「忘れても届く」では、フィボナッチ数の札 1, 2, 3, 5, 8, 13, 21 を一枚ずつ持ち、札の組み合わせで番地 1, 2, 3, … のすべてに届くことを見ました。4 は 1 ＋ 3、6 は 1 ＋ 5、7 は 2 ＋ 5、12 は 1 ＋ 3 ＋ 8。札は七枚しかないのに、33 までの番地に一つも欠けずに届きました（既存の言葉では：ツェッケンドルフの表現。フィボナッチ数の列は**完全**である）。

この章は、その続きです。手元の札を何枚か落としてしまったら、それでも全部の番地に届くでしょうか。

いちばん小さい 1 の札を落として、2, 3, 5, 8, 13, … だけにすると、1, 4, 6, 9, 12, 14, … と届かない番地が出てきます。しかも、大きな札をいくら足しても、届かない番地はどこまで行ってもなくなりません。

ここで、札の額面を少しだけ変えてみます。フィボナッチ数に、交互に 1 を足したり引いたりするのです。

> 2, 0, 3, 2, 6, 7, 14, 20, 35, 54, 90, 143, …

（0 の札は使いません。）この札は、小さいものを何枚落としても、十分大きな番地には必ず届きます。1964 年にグレアム（R. L. Graham）が見つけた性質です。

ハンガリーの数学者エルデシュは、生涯に何千もの問題を出し、解いた人に賞金を約束しました。その問題は今、erdosproblems.com に番号つきで集められています。この章で見る **#346** は、このグレアムの札から出てきた問題です。

> 札をいくつ落としても届く。けれども、無限に多く落とすと、もう届かなくなる。そういう札の額面は、隣どうしの比が必ず黄金比 φ に近づくのか。

この章では、グレアムの「1 を足したり引いたり」が、第1章の残渣そのものであることを見ていきます。

## 8.2 B13 の言葉で見ると

### 届く・届かない

第3章と同じく、数の列を札と見て、相異なる札をいくつか選んで足します。そうして届く番地を「届く数」、届かない番地を「穴」と呼びます。

- 十分大きな数がすべて届くとき、列は**完全**です（既存の言葉では：additively complete）。
- 先頭から何項落とした「尾」でも完全であるとき、列は**強く完全**です（既存の言葉では：strongly complete）。
- 隣り合う項の比が 1 より大きい一定の数を下回らないとき、列は**間がまばら**です（既存の言葉では：lacunary）。

第3章で見たとおり、フィボナッチの列は完全です。けれども強く完全ではありません。先頭の 1, 1 を落とすと、穴が尽きなくなります。

### 二つを一つに替える

フィボナッチの列では、隣り合う二つの項を足すと、ちょうど次の項になります。

> F(j) ＋ F(j＋1) ＝ F(j＋2)

これは、二枚の札を一枚に替えても、届く番地がまったく動かないということです。第3章の札の表現で、隣り合う札を一緒に使う必要が一度もなかったのは、このためです。小さい札を落とすと、その分の細かい調整をする手段がなくなり、穴が残ります。

グレアムの列 f(k) ＝ F(k) − (−1)^k では、こうなります。

> f(j) ＋ f(j＋1) ＝ f(j＋2) ＋ (−1)^j

二枚を一枚に替えると、届く番地がちょうど 1 だけ動きます。j が偶数なら 1 減り、奇数なら 1 増えます。この ±1 があるので、届いていた番地から 1 だけずれた番地にも届きます。小さい札を落としても、大きい札の替え方で、1 ずつの細かい調整ができるのです。

### その ±1 は、第1章の残渣

この (−1)^j は、どこから来たのでしょう。

第1章で、フィボナッチの点 (F(j＋1), F(j)) は、二本の双曲線

> x × x − x × y − y × y ＝ ±1

を交互に渡りました。その ±1 の符号が (−1)^j です。着地した側 φ^j と残渣の側 ψ^j を掛けると、(φψ)^j ＝ (−1)^j になりました（既存の言葉では：単数 φ^j のノルム N(φ^j) ＝ (−1)^j、カッシーニの恒等式）。

グレアムの列は、フィボナッチの各項に、この残渣の符号をそのまま足し引きしたものです。二枚を一枚に替えるたびに番地が動く 1 は、フィボナッチの残渣が生む「新しい 1」です。

［監督の発話］残渣が新しいフィボナッチの 1 を生む。

第1章で、二つの 1 には違う残渣がつくことを見ました。グレアムの列では、その残渣が、札を落としても届き続けるための 1 になっています。

### 比は φ の両側を渡る

グレアムの列の隣り合う項の比は

```
14/7 = 2.000   20/14 = 1.429   35/20 = 1.750   54/35 = 1.543
90/54 = 1.667  143/90 = 1.589  234/143 = 1.636  …   →  φ = 1.618…
```

と、φ の両側を交互に渡りながら φ に近づきます。点 (f(k＋1), f(k)) は、着地の線 x ＝ φy の右と左を交互に渡ります（第1章・第4章の双曲線と同じ渡り方です）。

ただし、素のフィボナッチとは一つ違いがあります。素のフィボナッチでは、点と着地の線の隔たり（残渣）は一歩ごとに縮んでいきました。グレアムの列では、隔たりはおよそ ±2.62 のまま縮みません［計算］。

```
k     5        6        7        8        9        10       11
隔たり −2.708   +2.674   −2.653   +2.639   −2.631   +2.626   −2.623   …  → ±φ²
```

f(k＋1) − φ f(k) は、F の残渣 ψ^k が消えたあとに (−1)^k (1 ＋ φ) ＝ ±φ² だけが残ります（既存の言葉では：φ² ＝ φ ＋ 1）。グレアムの列は、残渣を縮ませずに、一定の大きさで残し続ける列です。比が φ に近づくのは、隔たりが縮むからではなく、項のほうが大きくなるからです。

### #346 の問い

エルデシュ問題 #346 は、次の三つを同時に満たす列を考えます。

1. 間がまばら
2. 有限個の項をどう落としても、完全のまま
3. 無限個の項を落とすと、どの落とし方でも完全でなくなる

グレアムの列は、この三つを満たし、比は φ に近づきます。問いは、「三つを満たす列は、必ず比が φ に近づくのか」です。

B13 の言葉で言えば、「残渣の 1 で穴を埋め続ける列は、必ず φ の着地の線の両側を渡るしかないのか」という問いになります。

## 8.4 走らせた検定

**事前に決めたこと**

- 届く数は、整数を一本のビット列に見立て、項を一つ足すたびに「ずらして重ねる」だけで求める。足し算と比べ合いだけで、割り算・小数は使わない。
- 数 N に届くかどうかは N 以下の項だけで決まるので、窓（どこまで見るか）を 10⁶、10⁷、10⁸ の三通りに取る。最後の穴が三つの窓で同じで、しかも 10⁶ より手前にあれば、「穴はそこで尽きる」と読む。
- 検定1：フィボナッチの列は、尾 0・1 では穴が尽き、尾 2〜4 では窓を広げても穴が端まで残ること。
- 検定2：グレアムの列 F(k) − (−1)^k（小さい順に 2, 2, 3, 6, 7, 14, 20, …）は、尾 0〜4 のどれでも穴が尽きること。
- 検定3：j ＝ 1〜59 で、f(j) ＋ f(j＋1) − f(j＋2) ＝ (−1)^j と F(j＋1)² − F(j＋1)F(j) − F(j)² ＝ (−1)^j が、同じ符号で成り立つこと。
- 検定4（対照）：±1 を交互にせず、いつも ＋1 を足す列 F(k) ＋ 1 と、いつも 1 を引く列 F(k) − 1 で、検定2と同じことをする。
- 検定5：グレアムの列で、x² − xy − y²（x ＝ f(k＋1)、y ＝ f(k)）の符号が交互になること（比が φ の両側を交互に渡ること）。

**スクリプト（要所）**

```python
def last_hole(terms, U):
    """U 以下で、相異なる項の和で届かない最大の数。"""
    R = 1
    for t in terms:
        if t <= U: R = R | (R << t)      # ずらして重ねる
    s = bin((R & ((1 << (U + 1)) - 1)) | (1 << (U + 1)))[3:]
    i = s.find("0")                      # 上の桁から最初の穴
    return U - i if i >= 0 else 0
```

```
                     尾 3, 4: 同じく窓の端まで残る                              OK
検定2  グレアムの列  尾 0: 最後の穴 1      尾 1: 4      尾 2: 121      尾 3: 8858   （三つの窓で同じ）
                     尾 4: 999797 / 8556411 / 12080990（窓 10^6 では端まで残る）       NG
       追加の測定    尾 4 を窓 10^8 と 3×10^8 で比べる：どちらも 12080990
検定3  j = 1〜59 で両方とも (−1)^j                                              OK
検定4  対照 F(k) + 1：尾 0〜4 の最後の穴 1, 1, 11, 73, 2093（どの尾でも尽きる）

検定5  符号: −, +, −, +, −, +, …（交互）                                         OK
```

**読み**

- ［計算］素のフィボナッチの列は、先頭 2 項を落とすと、窓を 1 億まで広げても穴が端まで残りました。
- ［計算］グレアムの列は、尾 0〜3 で穴が 1, 4, 121, 8858 で尽きました。尾 4 では、穴の尽きる所が 12080990 にあり、事前に決めた「10⁶ より手前」の基準からは外れたため、検定2 の判定は NG です。追加の窓 10⁸ と 3 × 10⁸ では同じ 12080990 で止まったので、尾 4 でも穴は尽きていると読めます。尾を落とすごとに、穴の尽きる所は 1 → 4 → 121 → 8858 → 12080990 と急に遠くなり、尾 5 から先は窓 10⁸ では測れません。グレアムの列が「どの尾でも完全」であることは、1964 年の論文で証明されています。有限の窓で確かめられるのは、その最初のいくつかの尾までです。
- ［計算］±1 を交互にした残渣の符号は、第1章の双曲線の符号と、59 段すべてで一致しました。
- ［計算］対照のうち、いつも 1 を引く列 F(k) − 1 は、尾 1 から先で穴が尽きませんでした。いつも 1 を足す列 F(k) ＋ 1 は、この窓では尾 0〜4 のどれでも穴が尽き、対照として NG を返しませんでした。「±1 が交互であること」が完全性に必要かどうかは、この検定では切り分けられていません。

## 8.5 どこまで来ているか

［知識］エルデシュ問題 #346 は未解決です。erdosproblems.com では「有限の計算では解決できない」問題として分類されています。

- **グレアム（1964）**：f(k) ＝ F(k) − (−1)^k は、有限個のどの項を落としても完全で、無限個落とすとどの落とし方でも完全でなくなることを証明しました。論文の結びで、比の極限が φ でない、本質的に違う例があるかを問うています。これが #346 です。
- **エルデシュ＝グレアム（1980）**：比がいつも φ より大きければ、三つ目の条件（無限個落とすと壊れる）は自動的に満たされることを指摘しました。不規則な例なら作れることも述べています。
- **ファン・ドールン**：強く完全な列では、比が φ を下回ることが無限回起きることが示されています。したがって、比に極限があるなら、それは φ 以下です。

上からの押さえは済んでいて、残っているのは「φ より小さい極限を持つ例、あるいは極限を持たない例があるか」です。B13 の側では、グレアムの ±1 が第1章の残渣の符号そのものであること、その残渣が ±φ² の一定の大きさで残り続けることを、整数の検定で確かめたところまでです。

この章で見たのは、問題の入口にあるグレアムの列が、フィボナッチの残渣でできているということです。#346 を解いたわけではありません。

## 8.6 まとめ

第3章で見たとおり、フィボナッチの札は全部の番地に届きます。けれども二枚を一枚に替えても届く番地が動かないので、小さい札を落とすと、穴が尽きなくなります。

グレアムは、フィボナッチ数に ±1 を交互に足し引きしました。すると二枚を一枚に替えるたびに届く番地が 1 だけ動き、小さい札をいくつ落としても、十分大きな番地には届くようになりました。この ±1 は、第1章でフィボナッチの点が双曲線を渡るときの残渣の符号そのものです。残渣が、新しい 1 を生んでいます。

グレアムの列の比は、着地の線 x ＝ φy の両側を交互に渡りながら φ に近づきます。残渣は縮まずに ±φ² のまま残り続けます。残渣で穴を埋め続ける列は、必ずこの線の両側を渡るしかないのか。それがエルデシュ問題 #346 で、まだ答えは出ていません。
