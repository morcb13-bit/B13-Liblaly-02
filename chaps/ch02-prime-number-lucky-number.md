## 2.1 フィボナッチ数列は素数と項複数に分かれる

1 番から 100 番までの背番号をつけた 100 人が、番号順に一列に並んでいるとします。この列から人を外していくやり方を、二つ考えます。

**一つ目のやり方。** 「2 番の人から始めて、2 を足していった番号の人は外れてください」と言います。4 番、6 番、8 番…の人が外れます。次に、まだ残っている 3 番の人を選び、「3 を足していった番号の人は外れてください」と言います。6 番、9 番、12 番…です。これを続けます。外れるかどうかは、**背番号の値**で決まります。

**二つ目のやり方。** 「前から数えて 2 人目ごとに外れてください」と言います。列の 2 人目、4 人目、6 人目…が外れます。残った人で列を詰め、次に選ばれた数 3 を使って、「前から数えて 3 人目ごとに外れてください」と言います。外れるかどうかは、**列の中の順番**で決まります。

どちらも、選んだ数を手がかりに人を外していくだけの、よく似たやり方です。ところが、最後まで残る人の顔ぶれはまったく違います。一つ目のやり方で残るのは 1 番と**素数**の人、二つ目のやり方で残るのは**幸運数**の人です。

この章では、二つのやり方を同じ骨組みで書き、たった一行の違いで、数が素数と幸運数に分かれていく様子を見ます。

## 2.2 B13 の言葉で見ると

### 一つの骨組み

どちらの篩も、次の骨組みで書けます。

1. 1 から N までを並べる。
2. 前に選んだ数の次の生き残りを、「選ぶ数 s」とする（最初は 2）。
3. s を使って生き残りの一部を外す。
4. 2 に戻る。

違うのは 3 の一行だけです。

- **値で印をつける**：s に s を足し、さらに s を足し…と進んで、届いた値を外す。
- **番目で抜く**：生き残りを 1 から数え、s 番目ごとに外す。

どちらも、使っているのは足し算と数えることだけです。割り算も、余りの計算も使いません。

### 値と番目

第1章では、二つの 1 を別の札にして並べると、数が a の番地と b の番地の二つの列に分かれました。この章でも、同じ足し算の動きから二つの列が出てきます。分かれ目は、**何を数えるか**です。

- 値で印をつける篩は、数の大きさ（番地の値）に s を足していきます。外れる場所は、列がどう詰まっても変わりません。
- 番目で抜く篩は、今の生き残りの並び（列の中の順番）を数えます。一度外すと列が詰まるので、次に外れる場所は、それまでに何が外れたかで変わります。

値に足すか、並びを数えるか。この違いが、素数と幸運数を分けます。

## 2.4 走らせた検定

**事前に決めたこと**

- 篩は上の骨組みで、3 の一行だけを替えて二通り走らせる。足し算と数えることだけを使う。
- 検定A：値で印をつける篩の残りが「1 と素数」になり、番目で抜く篩の残りが幸運数になること。
  - 素数は、篩とは別の方法（どの数を足し重ねても届かないか）で確かめた列と照合する。
  - 幸運数は、知られている最初の 23 個［知識］と照合する。
- 検定B：10 万までで、素数と幸運数の個数、差が 2 の組（双子）の個数を数えて比べる。
- 検定C：20000 までの偶数が、二つの素数の和、二つの幸運数の和で書けるかを確かめる。
  - 負の対照：1 から 4 ずつ足した列（1, 5, 9, 13, …）。この列の二つの和は 4 の倍数にならないので、書けない偶数が出ること。

**スクリプト（要所）**

```python
def sieve(N, rule):
    seq = list(range(1, N + 1))
    prev = 1                          # 次に選ぶのは「前に選んだ数の次の生き残り」
    while True:
        nxt = [x for x in seq if x > prev]
        if not nxt: break
        s = nxt[0]
        if rule == "値":              # 値で印をつける：s ずつ足す
            if s + s > N: break
            hit = set()
            v = s + s
            while v <= N:
                hit.add(v); v += s
            seq = [x for x in seq if x not in hit]
        else:                         # 番目で抜く：s 個ずつ数える
            if s > len(seq): break
            out, c = [], 0
            for x in seq:
                c += 1
                if c == s: c = 0
                else: out.append(x)
            seq = out
        prev = s
    return seq
```

**結果**

```

**読み**

- ［計算］一行を替えるだけで、残りは 1 と素数から幸運数に替わりました。どちらも照合した列と一致しました。
- ［計算］個数は、10 万までで素数 9592 個、幸運数 8772 個でした。幸運数のほうが少し少ないまま、ほぼ同じ速さで増えていきます。差が 2 の組も、素数 1224 組、幸運数 1162 組と、よく似た数になりました。
- ［計算］20000 までの偶数は、どれも二つの素数の和でも、二つの幸運数の和でも書けました。対照の列では、4 の倍数が 5000 個すべて書けませんでした。
- ［見立て］値に足す篩と、並びを数える篩は、残る数の顔ぶれはまったく違うのに、残る数の**多さ**や**並び方の性質**はよく似ています。素数の性質の多くは、「値で印をつける」ことそのものより、「選んだ数で外し続ける」という篩の骨組みの側から来ているのかもしれません。

## 2.5 ペンローズタイリングに置き換えると

ここまでは、数を一列に並べて篩いました。同じ篩を、ペンローズタイリングの上に置き換えるとどう見えるかを確かめます。

### 数を円環の鎖で表す

五角形 10 枚でできた円環を 1 個とし、n 個の円環をつないだ鎖で数 n を表します。円環のつなぎ方は二種類だけです。

- **連続**：隣の円環と五角形を 2 枚共有してつなぐ。
- **飛ばし**：間を 2 つ飛ばしてつなぐ。

奇数の鎖は連続だけでつなぎ、108° ずつ交互に折れながら進むジグザグになります。偶数の鎖は飛ばしと連続を交互に使い、一直線に伸びます。1 から 13 までの鎖を上から順に積むと、91 環の三角形が重なりなく閉じます（前の記事の道具 b13_chain_units.py で、円環 91 個・五角形 628 枚・重なり 0 を確かめてあります）。

### 2 の打ちは「つなぎ方」、3 の打ちは「V 字」

- **2 の打ち**：飛ばしを含む鎖、つまり一直線の鎖が落ちます。数の値を見なくても、鎖の形で偶数が分かります。
- **3 の打ち**：奇数の鎖を、3 環の V 字で端から敷き詰めます。V 字だけでちょうど敷ける鎖が落ちます。

V 字で敷くと、余りの出方は三通りしかありません。

- 余りなし：V 字だけで敷ける（3, 9, 15, …）
- 1 環余る：真ん中に独立した 1 環が残る（7, 13, 19, …）
- 1 環重なる：真ん中で V 字を 1 環重ねる（5, 11, 17, …）

余る環も重なる環も、いつも鎖のちょうど真ん中に来ます。

図では、「2 の打ち」で一直線の鎖が暗くなり、「3 の打ち」で奇数の鎖が V 字に色分けされます。真ん中の余りや重なりには黄色の枠がつき、V 字だけで敷けた 9 が暗くなります。「残り」で、5, 7, 11, 13 が金色で残ります。

### 走らせた検定

**事前に決めたこと**

- 鎖とつなぎ方は、前の記事の b13_chain_units.py をそのまま使う。V 字の敷き詰めは chain_balanced.py の、V 字が座れる位置を形で調べる手順を使う。
- 2 の打ち：鎖が飛ばしを含むか。3 の打ち：独立した 1 の最小個数が 0 か（V 字だけで敷けるか）。
- 1〜29 で、2 の打ちと 3 の打ちのあとに残る数を、別の方法で確かめた素数と比べる。

**結果**

```

**読み**

- ［計算］13 段の三角形の中では、2 の打ちと 3 の打ちのあとに残るのは 5, 7, 11, 13 で、ちょうど 13 までの素数です。
- ［計算］29 まで広げると、素数はすべて残り、落ちる素数はありませんでした。素数でないのに残るのは 25 だけです。
- ［計算］25 を落とすには、次の打ち（5 の打ち）が要ります。ペンローズの鎖の形に直接現れるのは、2 の打ちと 3 の打ちまでです。
- 次の打ちの歩幅 5 は 2 + 3 です。その次の 7 は 2 + 2 + 3 です。どの歩幅も 2 と 3 を足して組めるので、5 から先の打ちも材料は 2 と 3 だけです。それを一列に並べて打っていったのが、2.4 の値で印をつける篩でした。

ペンローズタイリングの上では、素数は「2 と 3 で落ちなかった残り」として、形のまま見えます。その先の打ちは、同じ 2 と 3 を足して組んだ歩幅で、一列の篩が引き継ぎます。

## 2.6 どこまで来ているか

［知識］幸運数は 1950 年代に、計算機を使った研究の中で名づけられた数の列です。素数とよく似た性質を持つことが知られていて、たとえば N までの個数は、素数と同じくらいの速さで増えます。篩の外し方を偶然に任せても、残る数の多さは素数とよく似る、という研究もあります。

［知識］この章の検定 B と C で数えたことの裏には、まだ解かれていない問題があります。

- 差が 2 の素数の組（双子素数）は、どこまでも無限にあるか。これは**双子素数の予想**と呼ばれ、まだ解かれていません。
- 4 以上の偶数は、どれも二つの素数の和で書けるか。これは**ゴールドバッハの予想**と呼ばれ、非常に大きな数まで計算で確かめられていますが、まだ証明されていません。

幸運数についても、同じ形の問いが立てられ、計算の範囲では成り立っています［知識］。素数だけの性質だと思われていたものが、幸運数にも同じように現れることは、これらの問題が「値で印をつける」ことだけでなく、篩という骨組みそのものに関わっている可能性を示しています。

双子素数の問題は第5章で、素数の並び方の問題は第7章のリーマン予想で、もう一度見ます。

## 2.7 まとめ

人を外していく二つのやり方は、背番号の値で外すか、列の中の順番で外すかの一行しか違いません。その一行の違いで、残る数は素数と幸運数に分かれました。

それでいて、二つの列は、増え方も、差が 2 の組の多さも、偶数を二つの和で書けることも、よく似ていました。第1章で二つの 1 が数を二つの列に分けたように、この章では「値か番目か」という一つの分かれ目が、素数と幸運数という二つの家族を作っています。

ペンローズタイリングの上に置き換えると、2 の打ちは鎖のつなぎ方として、3 の打ちは V 字の敷き詰めとして、形のまま見えました。その先の打ちも、歩幅は 2 と 3 を足して組めます。

足し算の動きは同じで、数えるものだけが違う。その違いが、数の世界の分かれ道になっています。
